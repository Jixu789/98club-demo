# 98 CLUB｜复古游戏俱乐部

一个 Windows 98 风格的复古游戏俱乐部 Demo —— 90 分钟黑客松作品，零依赖、纯前端、可离线运行。

**在线体验**：<https://Jixu789.github.io/98club-demo/showcase.html>（视频 + 可玩 Demo 合并页）
**直接开玩**：<https://Jixu789.github.io/98club-demo/>

## 是什么

黑底 + 荧光绿 CRT 桌面，双击（单击）图标打开窗口：游戏大厅、排行榜、系统信息。
可以真的开房间、拉队友、准备、开局、结算，所有状态都是前端真实状态（刷新即复位）。

## 玩法（最短 3 步）

1. 点桌面「游戏大厅」→ 选一款游戏「创建房间」
2. 按「准备」，BOT 队友会自动就绪，全员就绪后房间状态转为「游戏中」
3. 点「模拟对局结算」→ 弹出金色胜利彩蛋，积分 +25，排行榜同步变化

## 本地运行

无需安装任何依赖，也不需要构建：

```bash
python -m http.server 8020
# 打开 http://localhost:8020（主 Demo）
# 打开 http://localhost:8020/showcase.html（视频 + 可玩合并页）
```

直接双击 `index.html` 也能运行（`file://` 打开时视频/iframe 行为依浏览器而定，建议用上面的本地服务）。

## 实现要点

- **零依赖**：不引 CDN、不用框架、不打包，路演现场断网也能跑。
- **窗口系统**：拖动（边界钳制）、层级 z-index 递增 + 7000 封顶重排、最小化与任务栏恢复。
- **房间状态机**：`waiting → playing`（全员就绪且人数 > 1）；真人全部离开则房间解散。
- **音效**：WebAudio 方波 8-bit 音效，默认关闭，任务栏 ♪ 按钮开启，无音频文件。
- **数据**：全部本地模拟，BOT 玩家显式标注为 BOT，不冒充真实在线用户。
